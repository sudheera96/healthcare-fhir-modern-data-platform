# Project Documentation

This directory contains the technical documentation for the Healthcare FHIR Modern Data Platform.

## Documentation Areas

- `architecture/` — system architecture, data flow, layers, and component responsibilities.
- `adr/` — Architecture Decision Records explaining important technical choices and tradeoffs.
- `data-quality/` — data-quality findings, validation results, and remediation decisions.
- `runbooks/` — operational troubleshooting and recovery procedures.
- `security/` — healthcare data security and HIPAA-aligned design considerations.

## Documentation Principle

The documentation intentionally records both successful implementation and platform limitations. This includes the Snowflake Trial Delta Sharing limitation and the decision to use Databricks SQL Dashboard instead of Omni.
